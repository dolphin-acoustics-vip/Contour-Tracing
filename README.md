Base files for whistle analysis using combined workflow developed by Paul Best and Charlie Hargrave. Predict.py contains the CNN model for frequency estimation. Details for its use, pretrained crepe model weights and all prerequisites can be found at https://github.com/mim-team/bioacoustic_F0_estimation. Gui.py generates an interactive plotting window for the manual evaluation and editing of these model estimations to correct for errors and misplaced points (includes quality of life improvements made by Tamra Chan, such as spectrogram customisation tools). ContourStats.py allows for the calculation of several time-frequency parameters used for tonal sound analysis to emulate those calculated by ROCCA for Pamguard, and is to be incorporated into the back end of the gui.py script.
